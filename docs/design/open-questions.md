## 이미 열린 구현 선택

- B: NLP model ID/revision·라이선스·tokenizer·길이/차원, 관계 이웃/시간쌍 예산, 개인화 step/lr/최소 데이터/validation 기준.
- C: 보호 프로토콜/버전·위협 가정·참여/이탈 하한·양자화·메시지 schema·실패/재시도. 보호 모드 최소 5명과 선택 프로토콜 조건을 함께 충족해야 한다.
- B/C: 화면 없는 실험에서 재사용할 집계 core API와 초기 release 등록 절차.
- 팀: 역할별 계정 선점(각 카드 2행), 제출일·발표 요구. CODEOWNERS 승인을 GitHub에 강제할지: 필수 승인 수를 1로 올리면 모든 PR이 승인을 기다리고, 0으로 두면 에이전트가 확인한다([Git 협업](../team/git-workflow.md) 'CI와 저장소 설정').

판매자가 통제하는 서버 환경의 존재를 시나리오 전제로 두고, 실제 서버 조달·설치·운영 제공 방식은 이번 범위 밖으로 둔다. 한 PC에서 논리적 판매자들을 모사하는 것이 기본이며 여러 PC 배치는 선택적 시연이다. 이는 서버 배포나 보안 구현을 완료했다는 뜻이 아니다([아키텍처](architecture.md)).

작은 고정 표본부터 비용과 작동 여부를 확인한다. test 결과로 hyperparameter를 고르지 않고, 합성 통과를 원자료 재현·모델 성능·보호 검증으로 대체하지 않는다. 미구현 게이트는 미구현 상태를 유지한다.
